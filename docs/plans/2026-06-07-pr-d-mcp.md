# Plan: PR D — read-only MCP server on `oceanln-httpd /mcp`

**Goal:** Mount an MCP server at `/mcp` on `oceanln-httpd` using
`rmcp 1.7`'s `StreamableHttpService`, behind the existing bearer-auth
middleware. Expose 7 read-only tools (4 OCEAN public-API proxies + 3
local wallet readers). Single `ServerHandler` implementation; all tool
handlers delegate to existing `oceanln_common` / `oceanln_httpd::service`
functions — **no duplicated business logic** (same architectural test as
PR A).

## Approach

Three layers, each strictly delegated to the one below it:

1. **Shared OCEAN-public-API Rust client** in `oceanln-common::ocean` —
   one shared `reqwest::Client` (connection pool), strongly-typed
   structs mirroring `oceanln-web/src/lib/ocean.ts` exactly. Handles
   the `{result} | {error}` envelope. Future callers (CLI, web
   backend, anything else) reuse this client instead of building
   their own.

2. **`oceanln-mcp::OceanMcpService`** — `#[tool_router(server_handler)]`
   on an impl block with 7 `#[tool(description = "...")]` methods.
   Each method delegates to an existing function:
   - `get_status()` → `oceanln_httpd::service::status`
   - `list_payouts(limit?)` → `oceanln_common::lexe_wallet::list_offer_payouts`
   - `get_ocean_stats(address)` → `oceanln_common::ocean::statsnap`
   - `get_ocean_hashrate(address)` → `oceanln_common::ocean::user_hashrate`
   - `get_ocean_earnings(address)` → `oceanln_common::ocean::earnpay`
   - `get_ocean_pool_stats()` → `oceanln_common::ocean::pool_stat`
   - `get_health()` → trivial `Ok("ok")` (no downstream)

   Rate-limit: one `tokio::sync::Semaphore(1)` per public-API tool to
   serialize calls to api.ocean.xyz from any single MCP session,
   preventing a looping AI from amplifying load.

3. **HTTP transport binding** in `oceanln-httpd::build_app`. Mount
   `/mcp` on the existing `protected` sub-router (which already has
   bearer-auth middleware). The auth bypass risk from research is
   addressed by mounting via `.route_service()` on the protected
   router (axum's layer-vs-route-service semantics still apply
   middleware), and **proven by integration test** (`POST /mcp`
   without bearer must return 401).

4. **Dashboard update** — `data.ts` switches to the real `addCmd`
   (the streamable-HTTP add syntax) and the panel shows `${app.base}/mcp`
   as the live endpoint. Drops the `Profile.svelte` "coming soon" copy.

## Edge cases (from parallel research)

- **#1 — auth bypass:** the mount via `route_service` on the protected
  router must NOT bypass the auth middleware. Caught by a dedicated
  integration test that hits `/mcp` without bearer.
- **#2 — bearer-token in tool descriptions:** none of the 7 tool
  descriptions contain example bearer tokens or seed phrases.
  Sentinel grep-check in the review pass.
- **#4 — OCEAN API rate amplification:** per-tool semaphore
  serializes requests to api.ocean.xyz.
- **#5 — body size limit:** `list_payouts` is capped at 100 by
  `MAX_PAYMENTS_BATCH_SIZE` in the wallet layer; no axum override
  needed.
- **#10 — connection pooling:** single `reqwest::Client` lives in
  `OceanMcpService` state, reused across all OCEAN-API tool calls.
- **CSP / TLS:** loopback-only by default, same posture as the
  rest of oceanln-httpd. Behind Umbrel/Start9's reverse proxy
  the connection picks up TLS for free.
- **Streamable-HTTP session manager:** use
  `LocalSessionManager::default()` (in-memory, single-user) —
  matches our deploy model.

## Test plan

- **Rust unit (oceanln-common):** OCEAN-client tests with fixture
  JSON ported from `oceanln-web/src/lib/Dashboard.test.ts` —
  proves each endpoint shape parses.
- **Rust integration (oceanln-mcp):** call each of the 7
  `#[tool]` methods through the rmcp `Service` trait directly,
  assert payloads. No HTTP layer in these tests.
- **Rust integration (oceanln-httpd/tests/server.rs):**
  - `POST /mcp` without bearer → 401 (auth-bypass regression test;
    this is the load-bearing one)
  - `POST /mcp` with bearer + `initialize` JSON-RPC frame → 200 with
    a valid MCP `serverInfo` response (proves the wire works)
- **Frontend:** no new tests needed — dashboard changes are display
  only. Existing tests stay green.

## Conventions

- `cargo fmt`, `cargo clippy -D warnings` (both full + thin
  `--no-default-features` build)
- New crate joins root workspace `members = [..., "oceanln-mcp"]`
- `mod tests` at the END of each file (clippy `items_after_test_module`)
- Public types derive `Debug + Clone + Serialize + Deserialize` for
  parity with the existing `OceanPayout` struct
- Bearer-token integration test runs against `MockWallet` — no
  Lexe backend needed
